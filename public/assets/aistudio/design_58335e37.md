### 1.2 Type

- **Headings:** Fraunces (serif), tight tracking, navy.
- **Body:** DM Sans (sans), 14–16px, generous line height.
- **Ticker:** bold uppercase with letter spacing for labels like `CANDIDATE`,
  `TRACK`, `ONE WORKING LIFE`.
- **Kbd:** monospace-ish, brackets, subtle background.

### 1.3 Layout

- Full-viewport card, no page scroll.
- Fixed-width block inside the card: top-to-bottom from the hero card.
- Footer pinned to the bottom of the stage.

## 2. Screens

### 2.1 Idle (`#start-screen`)

- Blue `Freebuff` pill + app name pill.
- Hero card with office/skyline art and a company plaque (TCS) for the player
  to relate to.
- Pill badge: `ONE WORKING LIFE · 75 SECONDS`.
- Heading `Hire & Fire.` + orange dot after the period.
- Subtitle: `Every gate is a company. Climb from campus placement to FAANG.
  Retire at 60 whether you like it or not.`
- **CANDIDATE** row: two candidate cards:
  - Boy card (white bg) + Girl card (navy bg); Girl selected by default.
  - Radio input + avatar silhouette + label on each card.
- **TRACK** row: three cards:
  - Fresher (white) — `First offer letter. Family is proud. Bond period included.`
  - Associate (navy) — `Two appraisals in. Still writing "as per my last email".`
  - Expert (white) — `Ten years in. You now interview the freshers who replaced you.`
- **Start** button (navy, pill): `Start your career →`.
- Key hint below: `[ Space ]` / tap to jump.
- Footer: trophy + `Best 0`, the promotion quote, speaker + fullscreen icons.

### 2.2 Stage / In-flight

- White canvas, no decorations atop the game. The stage is the scene: desks,
  skyline, company plaque on the right side.
- The career bar is a **secondary** element: subtle, non-blocking.

### 2.3 Playing (`#hud`)

- No stage UI: the arena is the stage; the HUD is the only UI.
- Career bar (in the HUD): `AGE 32` + progress bar (22 → 60, 75 s).
- `ROLE` label (group-name pill) + `PACKAGE: 2.1 Cr`.
- Score: `SCORE 24` plus a "companies cleared" eyebrow if > 0.
- The bird is the only gameplay element; the stage moves under it.

### 2.4 Paused (`#pause-screen`)

- Dark navy overlay; resume button + `Esc/P` hint.

### 2.5 Exit letter (`#result-screen`)

- Split layout: left art (bird on the floor) + right letter.
- Eyebrow: `EXIT` (Status-bad).
- Played company role, track, age, reason, score, package, best-personal-press.
- Big action: `Start another career` / `Change track`.

### 2.6 Retirement (`#retire`)

- Full-screen dark navy; retirement banner `Retired at 60. No pension.`
- Age 60, years worked, companies cleared, package LPA, role title.
- Action: `Start another career` / `Change track`.
- Job offer cards on the right for a future "keep working" branch.

## 3. Motion

- **Crop / fade in:** the start screen lifts, the stage reveals under the
  card, the bird lands for a heartbeat before the run.
- **Career bar:** fills in hard steps (ticks) with a subtle pulse at each
  company gate; slows near retirement.
- **Pipes:** glide horizontally (no bounce); the plaque slides left with the
  pipe, the gate opens/closes with a soft snap.
- **Result screen:** a paper-like reveal on the letter, a card flip on the
  score, and a staggered button list.
- **Particles:** a few contour particles on flap; a dust cloud on the floor
  (only when `prefers-reduced-motion` is off).
- **Retirement:** the bird drifts down; the banner slams in; the screen
  keeps the career bar at 100% and crosses it out.

## 4. Sound Design (Web Audio)

### 4.1 Architecture

- `Sound` class owns a `AudioContext` (created on first user gesture, or on
  `sound.unlock()` on resume). All sounds go through it.
- `decode()` caches `AudioBuffer` objects once; no on-the-fly decoding.
- `Sound.enabled` gate: every playback checks it; mute is a single bool.
- Toggle via `M`; persist to `localStorage`; update the speaker icon.
- The sound system is **opt-in by design** and never gates gameplay.

### 4.2 Sound events

| Event | Sound | Feel |
|---|---|---|
| Start / flap (any) | short blip, ~880 Hz, 60 ms | "point" arrival |
| Gate / cleared | high clean tone + soft click | company passed |
| Barrier (duck, close call) | low thump, 120 Hz, sharp attack | hazard warning |
| Retirement wall | sustained corporate bed + single chord | urgency |
| Retirement letter | gentle two-note "adieu" | resignation |
| Exit letter | resigned tone + low noise floor | "email" |
| Burnout | sharp flick | "draft rejected" |
| Start outro | short opener chord | "the offer" |

### 4.3 Corporate music bed

- A low, steady four-on-the-floor pulse (110 Hz kick, 8th notes) with a
  muted sitar/synth pad in the background — reads as "IT corridor" without
  being music. The bed **rises in intensity** as the career bar fills and
  **cuts out** on retirement, leaving quiet.

### 4.4 Per-track variations

- Fresher: soft, slightly detuned, warm.
- Associate: clean, mid-weight, corporate.
- Expert: bright, punchy, with a high-hat accent.
- FAANG ring: a fanfare chord on the first FAANG gate (decorative).

## 6. Build & Verify

1. `npm install` → `npm run typecheck` → `npm run build`.
2. `npm run dev` → `http://127.0.0.1:5188/` (port 5188 default).
3. Verify: start screen paints, Start works, HUD shows, space flap advances
   the career bar, a crashed run shows an exit letter, a 75 s run shows the
   retirement letter.
4. Deploy: a static host serving `dist/` (Nginx) or a Workers/edge host. The
   game has no server dependencies.
